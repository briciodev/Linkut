# Linkut
ENCURTADOR DE URL
🔗 Linkut — Encurtador de URLs

O Linkut é uma aplicação web para encurtar URLs e gerar QR Codes de forma simples, rápida e gratuita. Desenvolvido com HTML, CSS e JavaScript puro, o projeto combina um design moderno e responsivo com funcionalidades úteis para compartilhar links no dia a dia.

✨ Funcionalidades
🔗 Encurtamento de URLs: transforma links longos em links curtos utilizando uma API externa.
📱 Geração de QR Code: cria automaticamente um QR Code a partir do link encurtado.
📋 Copiar link: copia o link curto para a área de transferência.
📥 Download de QR Code: permite baixar o QR Code em formato PNG.
📱 Design responsivo: interface adaptada para computadores, tablets e celulares.
🎨 Interface moderna: gradientes, efeitos visuais, animações suaves e estilo dark.
✅ Validação de URLs: verifica o endereço informado antes de enviar a solicitação.
💬 Feedback visual: exibe mensagens de sucesso e erro durante as operações.
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript (ES6+)
QRCode.js
Shrtr API

⚙️ Como executar
Clone o repositório:
git clone https://github.com/SEU-USUARIO/linkut.git

Entre na pasta:
cd linkut

Abra a pasta no Visual Studio Code.
Execute o arquivo index.html com a extensão Live Server.
Digite uma URL e clique em Encurtar minha URL.

É necessário ter conexão com a internet para utilizar a API de encurtamento e carregar a biblioteca de QR Code.

💡 Como funciona?
O usuário informa uma URL.
O JavaScript valida o endereço.
A aplicação envia uma requisição à API Shrtr.
O link encurtado é exibido na tela.
O QR Code é gerado automaticamente.
O usuário pode copiar o link ou baixar o QR Code em PNG.
🌐 Limitações

O encurtamento depende da disponibilidade e dos limites da API externa. O projeto não possui backend próprio nem banco de dados.
